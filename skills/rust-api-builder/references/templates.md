# Templates

A complete `products` resource, followed by snippets for the add-ons. Every block below was copied
from a project generated from `assets/starter/`. That project builds with no clippy warnings and passes
its tests, and it was exercised over HTTP against Postgres and Redis: CRUD, filters, tenant isolation,
the error statuses, Excel import, cache-aside, activity logging, the proxy and a cron job.

Rename `product` / `products` / `Product` to your resource. Keep the shapes.

## 1. Migration

`diesel migration generate create_products` creates the folder; Diesel 2.3's CLI names it
`YYYY-MM-DD-HHMMSS-0000_<name>` (older projects have `YYYY-MM-DD-HHMMSS_<name>`; both sort correctly).
Then `diesel migration run` applies it and regenerates `schema.rs`, and `diesel migration redo` proves
`down.sql` works.

`migrations/<version>_create_products/up.sql`

```sql
CREATE TABLE IF NOT EXISTS products (
	id serial4 NOT NULL,
	company_code varchar(50) NOT NULL,
	name varchar(255) NOT NULL,
	description text NULL,
	stock int4 NOT NULL DEFAULT 0,
	status varchar(20) NOT NULL DEFAULT 'active',
	created_by varchar(100) NULL,
	created_at timestamptz NOT NULL DEFAULT NOW(),
	updated_at timestamptz NOT NULL DEFAULT NOW(),
	CONSTRAINT products_pk PRIMARY KEY (id),
	CONSTRAINT products_unique UNIQUE (company_code, name),
	CONSTRAINT products_status_check CHECK (status IN ('active', 'inactive'))
);

CREATE INDEX IF NOT EXISTS idx_products_company_code ON products (company_code);

SELECT diesel_manage_updated_at('products');
```

`migrations/<version>_create_products/down.sql`

```sql
DROP TABLE IF EXISTS products;
```

## 3. Entity

Three structs per table: `Product` (row, `Queryable + Selectable`), `NewProduct<'a>` (`Insertable`,
borrowing), and `ProductEntity` (what services use; the id is named `<entity>_id`).

## 5. Repository trait

`Send + Sync` plus `#[async_trait]` (not `?Send`), so services can also run inside cron jobs and
`tokio::spawn`. `automock` generates `MockProductRepositoryAbstract` for service tests.

## 6. Repository

Every method is `run_blocking(&self.pool, move |conn| { ... }).await`, so Diesel runs on the blocking
pool. Columns are referenced as `products::<column>`; avoid `use products::dsl::*` because a local
variable named like a column (`company_code`) silently shadows it. Tenant scope goes into the `WHERE`
of every read, update and delete. Zero affected rows on delete become `NotFound` (404).

`src/dataproviders/repositories/product_repository.rs`

```rust
use async_trait::async_trait;
use diesel::prelude::*;
use diesel::result::Error as DieselError;

use crate::application::mappers::db_mapper::DbMapper;
use crate::config::config_service::DbPool;
use crate::dataproviders::entities::product_entity::{NewProduct, Product, ProductEntity};
use crate::dataproviders::mappers::db::product_mappers::ProductDbMapper;
use crate::dataproviders::repositories::abstract_repository::product_repository_abstract::ProductRepositoryAbstract;
use crate::dataproviders::schema::schema::products;
use crate::delivery::domain::default::{DefaultHttpResponseDTO, QueryRequest};
use crate::delivery::domain::product_domain::{DeleteProductDTO, ProductDTO, UpdateProductDTO};
use crate::delivery::enums::status_enum::StatusEnum;
use crate::delivery::query::product_query::PRODUCT_QUERY_COLUMNS;
use crate::utils::db::{run_blocking, DbError};
use crate::utils::diesel_pagination::Paginate;

#[derive(Clone)]
pub struct ProductRepository {
    pub pool: DbPool,
}

#[async_trait]
impl ProductRepositoryAbstract for ProductRepository {
    async fn get_products(
        &self,
        query: QueryRequest,
        company_code: Option<String>,
    ) -> Result<(Vec<ProductEntity>, i64), DbError> {
        run_blocking(&self.pool, move |conn| {
            let mut statement = products::table.select(Product::as_select()).into_boxed();
            if let Some(code) = company_code {
                statement = statement.filter(products::company_code.eq(code));
            }

            let models = statement
                .paginate(&query, PRODUCT_QUERY_COLUMNS)?
                .load_and_count_pages::<Product>(conn)?;

            Ok((
                models
                    .0
                    .into_iter()
                    .map(ProductDbMapper::to_entity)
                    .collect::<Vec<ProductEntity>>(),
                models.1,
            ))
        })
        .await
    }

    async fn get_product(&self, product_id: i32, company_code: Option<String>) -> Result<ProductEntity, DbError> {
        run_blocking(&self.pool, move |conn| {
            let mut statement = products::table
                .filter(products::id.eq(product_id))
                .select(Product::as_select())
                .into_boxed();
            if let Some(code) = company_code {
                statement = statement.filter(products::company_code.eq(code));
            }

            let model = statement.first::<Product>(conn)?;

            Ok(ProductDbMapper::to_entity(model))
        })
        .await
    }

    async fn create_product(
        &self,
        data: ProductDTO,
        company_code: String,
        created_by: String,
    ) -> Result<ProductEntity, DbError> {
        run_blocking(&self.pool, move |conn| {
            let new_product = NewProduct {
                company_code: &company_code,
                name: &data.name,
                description: data.description.as_deref(),
                stock: data.stock,
                status: data.status.unwrap_or(StatusEnum::Active).as_str(),
                created_by: Some(&created_by),
            };

            let model = diesel::insert_into(products::table)
                .values(&new_product)
                .returning(Product::as_returning())
                .get_result(conn)?;

            Ok(ProductDbMapper::to_entity(model))
        })
        .await
    }

    async fn update_product(
        &self,
        data: UpdateProductDTO,
        company_code: Option<String>,
    ) -> Result<ProductEntity, DbError> {
        run_blocking(&self.pool, move |conn| {
            let changes = (
                products::name.eq(data.name),
                products::description.eq(data.description),
                products::stock.eq(data.stock),
                products::status.eq(data.status.as_str()),
            );

            // updated_at is set by the diesel_manage_updated_at trigger
            let model = match company_code {
                Some(code) => diesel::update(
                    products::table
                        .filter(products::id.eq(data.id))
                        .filter(products::company_code.eq(code)),
                )
                .set(changes)
                .returning(Product::as_returning())
                .get_result(conn)?,
                None => diesel::update(products::table.filter(products::id.eq(data.id)))
                    .set(changes)
                    .returning(Product::as_returning())
                    .get_result(conn)?,
            };

            Ok(ProductDbMapper::to_entity(model))
        })
        .await
    }

    async fn delete_product(
        &self,
        data: DeleteProductDTO,
        company_code: Option<String>,
    ) -> Result<DefaultHttpResponseDTO, DbError> {
        run_blocking(&self.pool, move |conn| {
            let deleted = match company_code {
                Some(code) => diesel::delete(
                    products::table
                        .filter(products::id.eq(data.id))
                        .filter(products::company_code.eq(code)),
                )
                .execute(conn)?,
                None => diesel::delete(products::table.filter(products::id.eq(data.id))).execute(conn)?,
            };

            if deleted == 0 {
                return Err(DieselError::NotFound.into());
            }

            Ok(DefaultHttpResponseDTO::success("success"))
        })
        .await
    }
}
```

## 7. Query whitelist

must not probe (secrets, internal flags). `id` must be listed because the default sort is `id,DESC`.

## 8. DTOs

`camelCase` JSON. Enum fields (`StatusEnum`) reject unknown values at deserialization (400).
`companyCode` in a request body is honoured for superadmin only, which the service enforces.

`src/delivery/domain/product_domain.rs`


## 9. Service

Holds `&'a dyn <X>RepositoryAbstract` and is built per request in the controller. It enforces business rules
and tenant scope (`claim.scoped_company_code(...)`), and turns repository errors into `ApiError` with
`ErrorHandling::repository_error("<fixed message>", e)`. The tests use the mockall mock.

`src/usecases/product_service.rs`

```rust
use actix_web::HttpRequest;

use crate::application::error::error_handling::ErrorHandling;
use crate::dataproviders::entities::product_entity::ProductEntity;
use crate::dataproviders::repositories::abstract_repository::product_repository_abstract::ProductRepositoryAbstract;
use crate::delivery::domain::default::{DefaultHttpResponseDTO, QueryRequest};
use crate::delivery::domain::error::ApiError;
use crate::delivery::domain::product_domain::{DeleteProductDTO, ProductDTO, UpdateProductDTO};
use crate::delivery::interfaces::general_interface::Claims;
use crate::utils::convert::query_transform;

pub struct ProductService<'a> {
    repository: &'a dyn ProductRepositoryAbstract,
}

impl<'a> ProductService<'a> {
    pub fn new(repository: &'a dyn ProductRepositoryAbstract) -> Self {
        ProductService { repository }
    }

    pub async fn get_products(
        &self,
        request: HttpRequest,
        claim: &Claims,
    ) -> Result<(Vec<ProductEntity>, i64), ApiError> {
        let query_params = query_transform(request.query_string())
            .map_err(|e| ErrorHandling::application_error(&e.to_string(), Some(e.into())))?;

        self.query_products(query_params, claim).await
    }

    /// Same as `get_products` for callers that build the query themselves (other services, jobs).
    pub async fn query_products(
        &self,
        query: QueryRequest,
        claim: &Claims,
    ) -> Result<(Vec<ProductEntity>, i64), ApiError> {
        // superadmin sees every company and may narrow with `company_code.equal=<code>`
        let get_data = self
            .repository
            .get_products(query, claim.scoped_company_code(None))
            .await;

        match get_data {
            Ok(results) => Ok(results),
            Err(e) => Err(ErrorHandling::repository_error("Cannot get all products", e)),
        }
    }

    pub async fn get_product(&self, product_id: i32, claim: &Claims) -> Result<ProductEntity, ApiError> {
        let get_data = self
            .repository
            .get_product(product_id, claim.scoped_company_code(None))
            .await;

        match get_data {
            Ok(result) => Ok(result),
            Err(e) => Err(ErrorHandling::repository_error("Product not found", e)),
        }
    }

    pub async fn create_product(&self, data: ProductDTO, claim: &Claims) -> Result<ProductEntity, ApiError> {
        if data.name.trim().is_empty() {
            return Err(ErrorHandling::application_error("name is required", None));
        }
        if data.stock < 0 {
            return Err(ErrorHandling::application_error("stock cannot be negative", None));
        }

        let company_code = claim
            .scoped_company_code(data.company_code.clone())
            .ok_or_else(|| ErrorHandling::application_error("companyCode is required", None))?;

        let insert = self
            .repository
            .create_product(data, company_code, claim.username.clone())
            .await;

        match insert {
            Ok(result) => Ok(result),
            Err(e) => Err(ErrorHandling::repository_error("Cannot create product", e)),
        }
    }

    pub async fn update_product(&self, data: UpdateProductDTO, claim: &Claims) -> Result<ProductEntity, ApiError> {
        if data.name.trim().is_empty() {
            return Err(ErrorHandling::application_error("name is required", None));
        }

        let update = self
            .repository
            .update_product(data, claim.scoped_company_code(None))
            .await;

        match update {
            Ok(result) => Ok(result),
            Err(e) => Err(ErrorHandling::repository_error("Cannot update product", e)),
        }
    }

    pub async fn delete_product(
        &self,
        data: DeleteProductDTO,
        claim: &Claims,
    ) -> Result<DefaultHttpResponseDTO, ApiError> {
        let delete = self
            .repository
            .delete_product(data, claim.scoped_company_code(None))
            .await;

        match delete {
            Ok(result) => Ok(result),
            Err(e) => Err(ErrorHandling::repository_error("Cannot delete product", e)),
        }
    }
}
```

## Adding an env var

1. Read it where it's used: `self.config_service.get_env("UPSTREAM_URL")` (required; panics with
   `UPSTREAM_URL must be set`) or `get_env_or("UPSTREAM_TIMEOUT", "30")` (optional with default).

2. Add the key to `.env.example` with a safe placeholder (never a real secret).
3. Add it to the deployment: plain `env` in the manifest for non-secrets, the Kubernetes Secret
   for anything sensitive.

## Cache-aside on a read endpoint

Key builder shared by read and invalidate; the key includes every input that changes the result
(tenant scope + id). Cache errors are logged, never returned. Writes invalidate before they run.

```rust
#[get("/{product_id}")]
async fn get_product(
    ctx: web::Data<GeneralModules>,
    path: web::Path<(i32,)>,
    claim: ClaimGuardMiddleware,
) -> Result<HttpResponse, CustomErrorResponse> {
    role_guard(&claim, READ_ROLES)?;
    let product_id = path.into_inner().0;

    // cache-aside: the key holds every input that changes the result (tenant scope + id)
    let scope = claim.scoped_company_code(None).unwrap_or_else(|| "all".to_owned());
    let cache_key = product_cache_key(&scope, product_id);
    let redis = RedisService::new(&ctx.redis);

    match redis.get(&cache_key).await {
        Ok(Some(cached)) => {
            return Ok(HttpResponse::Ok().content_type("application/json").body(cached));
        }
        Ok(None) => (),
        Err(e) => log::warn!("product cache read failed: {}", e),
    }

    let entity = ProductService::new(&ctx.product_repository)
        .get_product(product_id, &claim)
        .await
        .map_err(CustomErrorResponse::map_io_error)?;
    let response = ProductApiMapper::to_api(entity);

    if let Ok(serialized) = serde_json::to_string(&response) {
        if let Err(e) = redis.set(&cache_key, &serialized, Some(PRODUCT_CACHE_TTL)).await {
            log::warn!("product cache write failed: {}", e);
        }
    }

    Ok(HttpResponse::Ok().json(response))
}

const PRODUCT_CACHE_TTL: u64 = 300;

fn product_cache_key(scope: &str, product_id: i32) -> String {
    format!("product:one:{}:{}", scope, product_id)
}

/// Drops every cached copy of a product: the owner's and the superadmin ("all") one.
async fn invalidate_product_cache(ctx: &GeneralModules, product_id: i32) {
    if let Err(e) = RedisService::new(&ctx.redis)
        .delete_pattern(&product_cache_key("*", product_id))
        .await
    {
        log::warn!("product cache invalidation failed: {}", e);
    }
}
```

In `update_product` / `delete_product`, right after parsing the body:

```rust
    invalidate_product_cache(&ctx, body.id).await;
```

For cached lists, put the tenant scope, the filters, the sort, the page and the size in the key (for example
`product:list:<scope>:<sha of query_string>`) and invalidate with `delete_pattern("product:list:<scope>:*")`
plus the `all` scope.

Service-to-service calls (log engine, query engine, other internal APIs) authenticate with a token

```rust
use std::collections::HashMap;

use redis::aio::ConnectionManager;
use serde_json::json;

use crate::config::config_service::ConfigService;
use crate::delivery::domain::error::ApiError;
use crate::delivery::domain::request_domain::RequestOptionDomain;
use crate::delivery::interfaces::auth_interface::AuthTokenResponse;
use crate::usecases::redis_service::RedisService;
use crate::usecases::request_service::RequestService;

const MACHINE_TOKEN_KEY: &str = "token:auth-engine:machine";

/// Service-to-service token from the auth engine (password grant with the service account),
/// cached in redis until shortly before it expires.
pub struct AuthService<'a> {
    config_service: &'a ConfigService,
    http_client: &'a reqwest::Client,
    redis: &'a ConnectionManager,
}

impl<'a> AuthService<'a> {
    pub fn new(
        config_service: &'a ConfigService,
        http_client: &'a reqwest::Client,
        redis: &'a ConnectionManager,
    ) -> Self {
        AuthService {
            config_service,
            http_client,
            redis,
        }
    }

    pub async fn get_machine_token(&self) -> Result<String, ApiError> {
        match RedisService::new(self.redis).get(MACHINE_TOKEN_KEY).await {
            Ok(Some(token)) => return Ok(token),
            Ok(None) => (),
            Err(e) => log::warn!("cannot read cached machine token: {}", e),
        }

        let payload = json!({
            "grant_type": "password",
            "username": self.config_service.get_env("AUTH_ENGINE_USER"),
            "password": self.config_service.get_env("AUTH_ENGINE_PASSWORD"),
            "scope": "read_write",
            "type": "superadmin",
        });

        let response = RequestService::new(self.http_client)
            .request_json::<AuthTokenResponse>(RequestOptionDomain {
                method: "POST".to_owned(),
                url: format!("{}/v1/oauth/tokens", self.config_service.get_env("AUTH_ENGINE_URL")),
                payload: payload.to_string(),
                headers: HashMap::from([
                    (
                        "Content-Type".to_owned(),
                        "application/x-www-form-urlencoded".to_owned(),
                    ),
                    (
                        "Authorization".to_owned(),
                        format!("Basic {}", self.config_service.get_env("AUTH_BASIC_KEY")),
                    ),
                ]),
            })
            .await?;

        // refresh a minute early
        let ttl = response.expires_in.unwrap_or(3600).saturating_sub(60).max(60);
        if let Err(e) = RedisService::new(self.redis)
            .set(MACHINE_TOKEN_KEY, &response.id_token, Some(ttl))
            .await
        {
            log::warn!("cannot cache machine token: {}", e);
        }

        Ok(response.id_token)
    }
}
```

Env: `AUTH_ENGINE_URL`, `AUTH_BASIC_KEY` (base64 `client:secret`), `AUTH_ENGINE_USER`,
`AUTH_ENGINE_PASSWORD`. Register `pub mod auth_interface;` and `pub mod auth_service;`.

```rust
            }
```

```rust
                payload,
                headers: HashMap::from([("Authorization".to_owned(), format!("Bearer {}", token))]),
```

## Proxy / integration endpoint (no database)

A catch-all route that forwards to an upstream with server-side credentials. A service that only
does this needs no pool, migrations or repositories (see new-project.md, "Trim").

`src/usecases/proxy_service.rs`

```rust
use std::collections::HashMap;

use actix_web::HttpRequest;
use serde_json::Value;

use crate::application::error::error_handling::ErrorHandling;
use crate::config::config_service::ConfigService;
use crate::delivery::domain::error::ApiError;
use crate::delivery::domain::request_domain::RequestOptionDomain;
use crate::delivery::interfaces::general_interface::Claims;
use crate::usecases::request_service::RequestService;

/// Client headers passed through to the upstream; everything else is dropped.
const FORWARDED_HEADERS: [&str; 4] = ["user-agent", "referer", "x-forwarded-for", "cf-ipcountry"];

pub struct ProxyService<'a> {
    config_service: &'a ConfigService,
    http_client: &'a reqwest::Client,
}

impl<'a> ProxyService<'a> {
    pub fn new(config_service: &'a ConfigService, http_client: &'a reqwest::Client) -> Self {
        ProxyService {
            config_service,
            http_client,
        }
    }

    /// Forwards `{scope}/{path}?{query}` to `{UPSTREAM_URL}/{path}?{query}` with the same method,
    /// adding the upstream credentials and the caller's identity.
    pub async fn forward(&self, request: &HttpRequest, body: String, claim: &Claims) -> Result<Value, ApiError> {
        let path = request.match_info().get("path").unwrap_or_default();
        if path.split('/').any(|segment| segment == "..") {
            return Err(ErrorHandling::application_error("invalid path", None));
        }

        let mut url = format!("{}/{}", self.config_service.get_env("UPSTREAM_URL"), path);
        if !request.query_string().is_empty() {
            url.push('?');
            url.push_str(request.query_string());
        }

        let mut headers = HashMap::from([
            (
                "x-endpoint-secret".to_owned(),
                self.config_service.get_env("UPSTREAM_SECRET_KEY"),
            ),
            ("x-company-code".to_owned(), claim.company_code.clone()),
        ]);
        for (key, value) in request.headers() {
            if FORWARDED_HEADERS.contains(&key.as_str()) {
                if let Ok(value) = value.to_str() {
                    headers.insert(key.as_str().to_owned(), value.to_owned());
                }
            }
        }

        RequestService::new(self.http_client)
            .request_json::<Value>(RequestOptionDomain {
                method: request.method().to_string(),
                url,
                payload: body,
                headers,
            })
            .await
    }
}
```

`src/delivery/rest/proxy_controller.rs`

```rust
use actix_web::{route, web, HttpRequest, HttpResponse};

use crate::application::guards::claim_guard::ClaimGuardMiddleware;
use crate::application::modules::general_modules::GeneralModules;
use crate::delivery::domain::error::CustomErrorResponse;
use crate::usecases::proxy_service::ProxyService;

pub fn routes(cfg: &mut web::ServiceConfig) {
    cfg.service(proxy_request);
}

// gateway spec path: /api/v1/upstream/{url=**}, one operation per method
#[route("/{path:.*}", method = "GET", method = "POST", method = "PUT", method = "DELETE")]
async fn proxy_request(
    ctx: web::Data<GeneralModules>,
    request: HttpRequest,
    body: web::Bytes,
    claim: ClaimGuardMiddleware,
) -> Result<HttpResponse, CustomErrorResponse> {
    let body = String::from_utf8_lossy(&body).into_owned();

    let results = ProxyService::new(&ctx.config_service, &ctx.http_client)
        .forward(&request, body, &claim)
        .await;

    results

        .map(|response| HttpResponse::Ok().json(response))
}
```

token, cache it under `token:<integration>:<companyCode>:<username>` with a TTL a bit shorter than the token's.

```rust
/// Registers recurring jobs. Cron has six fields, seconds first: "0 */5 * * * *" = every 5 minutes.
/// With more than one replica every replica runs every job; guard jobs that must run once with a
/// redis lock (SET key NX EX).
pub async fn register_jobs(ctx: web::Data<GeneralModules>) -> Result<(), JobSchedulerError> {
    let job_ctx = ctx.clone();
    let low_stock_job = Job::new_async("0 */5 * * * *", move |_job_id, _scheduler| {
        let ctx = job_ctx.clone();
        Box::pin(async move {
            // jobs act as the system, across every company
            let system = Claims {
                role: ROLE_SUPERADMIN.to_owned(),
                username: "system".to_owned(),
                ..Default::default()
            };
            let query = QueryRequest::default().with_filter("stock", "lessThan", "5");

            match ProductService::new(&ctx.product_repository)
                .query_products(query, &system)
                .await
            {
                Ok((_, total)) => log::info!("low stock products: {}", total),
                Err(e) => log::error!("low stock job failed: {}", e),
            }
        })
    })?;

    ctx.scheduler.add(low_stock_job).await?;

    Ok(())
}
```

Register in `run()` after `GeneralModules` is built:

```rust
use crate::usecases::job_service::register_jobs;
// ...
    register_jobs(data.clone()).await.map_err(std::io::Error::other)?;
```

The closure must return a `Send` future, which is why repository traits are `Send + Sync`. To remove a
job later, keep the `Uuid` returned by `scheduler.add(job)` (for example in redis under
`<feature>:job:<id>`) and call `ctx.scheduler.remove(&uuid)`.

## Excel import (multipart upload + calamine + transactional bulk insert)

`Cargo.toml`: `calamine = "0.36"`.

`src/usecases/excel_service.rs`

```rust
use calamine::{open_workbook, Data, DataType, Reader, Xlsx};

use crate::delivery::domain::product_domain::ProductDTO;

pub struct ExcelService {}

impl ExcelService {
    /// Reads `Sheet1`: header row, then `name | stock` per row. Blocking: call it inside
    /// `web::block`. Returns the rows and the 1-based row numbers that were skipped.
    pub fn read_products(pathfilename: &str) -> Result<(Vec<ProductDTO>, Vec<usize>), calamine::Error> {
        let mut workbook: Xlsx<_> = open_workbook(pathfilename)?;
        let range = workbook.worksheet_range("Sheet1")?;

        let mut products: Vec<ProductDTO> = Vec::new();
        let mut skipped: Vec<usize> = Vec::new();

        for (index, row) in range.rows().enumerate().skip(1) {
            let name = row.first().map(|cell| cell.to_string()).unwrap_or_default();
            let stock = row.get(1).and_then(|cell: &Data| cell.as_i64()).unwrap_or(0);

            if name.trim().is_empty() || stock < 0 || stock > i32::MAX as i64 {
                skipped.push(index + 1);
                continue;
            }

            products.push(ProductDTO {
                company_code: None,
                name: name.trim().to_owned(),
                description: None,
                stock: stock as i32,
                status: None,
            });
        }

        Ok((products, skipped))
    }
}
```

```rust
    async fn bulk_insert_products(
        &self,
        data: Vec<ProductDTO>,
        company_code: String,
        created_by: String,
    ) -> Result<usize, DbError> {
        run_blocking(&self.pool, move |conn| {
            // all rows or none; a duplicate name rolls back the whole file
            conn.transaction::<_, DbError, _>(|conn| {
                let mut inserted = 0;
                // stay well under Postgres' 65535 bind parameters per statement
                for chunk in data.chunks(1000) {
                    let rows = chunk
                        .iter()
                        .map(|product| NewProduct {
                            company_code: &company_code,
                            name: &product.name,
                            description: product.description.as_deref(),
                            stock: product.stock,
                            status: product.status.unwrap_or(StatusEnum::Active).as_str(),
                            created_by: Some(&created_by),
                        })
                        .collect::<Vec<NewProduct>>();

                    inserted += diesel::insert_into(products::table).values(&rows).execute(conn)?;
                }
                Ok(inserted)
            })
        })
        .await
    }
```

Service method (add `use actix_web::web;` and `use crate::usecases::excel_service::ExcelService;`):

```rust
    /// Imports every uploaded workbook, then deletes the files.
    pub async fn import_products(
        &self,
        filepaths: Vec<String>,
        claim: &Claims,
    ) -> Result<DefaultHttpResponseDTO, ApiError> {
        let company_code = claim.scoped_company_code(None).ok_or_else(|| {
            ErrorHandling::application_error("superadmin must import through a company account", None)
        })?;

        let mut imported = 0;
        let mut skipped_rows = 0;
        for filepath in filepaths {
            let path = filepath.clone();
            let parsed = web::block(move || ExcelService::read_products(&path)).await;
            let _ = std::fs::remove_file(&filepath);

            let (rows, skipped) = match parsed {
                Ok(Ok(result)) => result,
                Ok(Err(e)) => {
                    return Err(ErrorHandling::application_error(
                        "Cannot read the workbook",
                        Some(e.into()),
                    ))
                }
                Err(e) => {
                    return Err(ErrorHandling::internal_error(
                        "Cannot read the workbook",
                        Some(e.into()),
                    ))
                }
            };
            skipped_rows += skipped.len();

            imported += self
                .repository
                .bulk_insert_products(rows, company_code.clone(), claim.username.clone())
                .await
                .map_err(|e| ErrorHandling::repository_error("Cannot import products", e))?;
        }

        Ok(DefaultHttpResponseDTO::success(&format!(
            "imported {} products, skipped {} rows",
            imported, skipped_rows
        )))
    }
```

Controller route (register `.service(import_products)` **before** `.service(get_product)`; add `use actix_multipart::Multipart;` and `multipart_to_files` to the imports; add `product_controller::import_products` to `ApiDoc`):

```rust
#[utoipa::path(
    post,
    path = "/api/v1/product/import",
    tag = "product",
    request_body(content = String, content_type = "multipart/form-data", description = "one or more .xlsx files: Sheet1, header row, then name | stock"),
    responses(
        (status = 200, description = "Succesfully", body = DefaultHttpResponseDTO),
        (status = 400, description = "Unreadable workbook", body = ErrorPresenter)
    ),
    security(("authorization" = []))
)]
#[post("/import")]
async fn import_products(
    ctx: web::Data<GeneralModules>,
    payload: Multipart,
    claim: ClaimGuardMiddleware,
) -> Result<HttpResponse, CustomErrorResponse> {
    role_guard(&claim, WRITE_ROLES)?;
    let filepaths = multipart_to_files(payload, "public/assets/files").await?;

    let results = ProductService::new(&ctx.product_repository)
        .import_products(filepaths, &claim)
        .await;

    results
        .map_err(CustomErrorResponse::map_io_error)
        .map(|response| HttpResponse::Ok().json(response))
}
```

`multipart_to_files` (starter) strips directories from the client's file name, prefixes a uuid
and enforces `MAX_UPLOAD_SIZE`. The service deletes each file after reading it.
